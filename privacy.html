隐私权政策

最后更新：2026 年 10 月 16 日

Droid Drive MCP（以下简称「本应用」）是一个在用户本人电脑上运行的本地工具，用于让 Droid 助手通过用户自己授权的 Google 账号访问其 Google Drive。

1. 访问的数据

本应用只访问用户本人通过 Google 授权的 Google Drive 数据，授权范围为 https://www.googleapis.com/auth/drive。

2. 数据如何处理

  • OAuth 令牌和客户端配置只保存在用户本机，不上传到任何服务器。
  • 本应用没有由开发者运营的服务器。开发者不收集、不保存、不出售用户数据。
  • 本应用只与 Google 的 API 端点通信（oauth2.googleapis.com 和 www.googleapis.com）。不包含第三方分析、广告或遥测组件。
  • 通过本应用读取的文件内容，会作为工具结果提供给用户所使用的 AI 助手（Droid）处理。这部分处理遵循该服务的条款。用户可以自行决定让哪些文件被读取。

3. Google API 用户数据政策

本应用使用 Google API 获取的信息，遵守 Google API 服务用户数据政策，包括其中的有限使用（Limited Use）要求。

4. 用户控制

  • 可随时在 Google 账号的「第三方访问」页面撤销本应用的授权。
  • 删除用户本机的 gdrive_tokens.json 文件，即可删除本地保存的令牌。
